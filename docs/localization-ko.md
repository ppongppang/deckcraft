# Korean interface fork

This fork adds a Korean interface catalog, a saved auto/en/ko language setting, View and Preferences
selectors and the `app.language` command. English tab names, command ids, document values and
automation protocols are unchanged. Korean command search also accepts canonical English names.

The catalog contains 1,301 entries (including technical names and shortcut strings intentionally
kept unchanged). Ribbon captions are measured after translation. UI string literals, command
labels, dialogs, task panes, tooltips and common formatted counters are connected to the catalog.
Strings generated by other model helpers and uncommon engine errors can still fall back to English.

The patch also adds IME preedit/commit handling for the slide canvas. Preedit is a temporary overlay;
only committed text enters the presentation and undo history. A candidate-window rectangle is
provided for text shapes and table cells. Existing egui text fields handle their own composition.
Regression tests include Hangul syllable updates, late commits after cancellation and a single
document undo step. These tests have NOT been run in the authoring environment.

Nanum Gothic (NHN/NAVER, SIL OFL 1.1) is added through an external craft-fonts input at Windows CI
build time. Proprietary fonts are not copied or bundled. The UI installs Hang-script faces from that
input, so Korean captions do not depend on a particular font already installed on the user's PC.

Validation completed: TSV structure, duplicate keys, escape sequences, placeholders, ellipses,
structural tab/command ids and lexical Rust delimiter checks. Validation still required: Rust
compilation, cargo xtask ci, a rendered UI inspection, Windows IME behavior and PPTX/PDF round trips.
The authoring host has no Rust toolchain, its terminal cannot access the network and browser
automation is unavailable. The Windows workflow is prepared but has not been executed.
